# Glossaire

| Terme | Définition |
| --- | --- |
| UHC | Ultra Hardcore : mode de survie où la vie ne se régénère pas naturellement et où la mort est définitive |
| Alter | Pouvoir d'un personnage dans My Hero Academia. En jeu : un pouvoir actif, porté par une étoile du Nether |
| Hôte / staff | Joueur qui configure et lance la partie |
| Compo | Composition : la liste des rôles actifs pour la partie |
| Camp | Équipe d'un joueur, avec laquelle il gagne |
| Solitaire | Joueur qui gagne seul |
| Groupes | Nombre maximal de joueurs autorisés à se déplacer ensemble |
| Kill / assistance | Élimination d'un joueur / présence à moins de 25 blocs du tueur |
| Temps de recharge (cooldown) | Délai avant de pouvoir réutiliser un pouvoir, noté « 1x/5min » |
| Cœur | 2 points de vie. Un cœur permanent modifie la vie maximale |
| Stun | Étourdissement : le joueur ne peut ni bouger ni tourner la caméra |
| Accroupi + clic droit | Seconde action de certains pouvoirs (« sneak ») |
| Symbole de la paix | Héros désigné au hasard, qui ignore la Force adverse |
| Manipulable | Joueur recruté par les Préceptes via la Manipulation d'Overhaul |
| QG | Quartier général des Préceptes : labyrinthe où se joue le sort d'Eri |
| Néant | Arène à part où Black Mist enferme des joueurs |
| Yuei | Lycée qui apparaît temporairement et cache des informations |
| Final Heal | Soin complet de tous les joueurs, déclenché par l'hôte |

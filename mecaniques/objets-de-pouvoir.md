# Objets de pouvoir

- Chaque pouvoir actif est une étoile du Nether nommée, reçue en début de partie.
- Clic droit avec l'étoile en main pour utiliser le pouvoir. Certains pouvoirs ont une seconde action avec accroupi + clic droit.
- En tenant l'étoile, la barre d'action indique si le pouvoir est utilisable ou son temps de recharge restant. Un message prévient quand il est rechargé.
- Les étoiles sont verrouillées dans l'inventaire : elles ne peuvent pas être jetées et ne tombent pas à la mort.

{% hint style="info" %}
Si l'inventaire est plein, l'objet est mis de côté et se récupère avec `!claim`.
{% endhint %}

- Un joueur sous l'Effacement d'Aizawa ne peut utiliser aucun pouvoir.

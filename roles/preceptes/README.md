# Rôles Préceptes

{% hint style="info" %}
Les quatre Préceptes partagent les mêmes avantages de camp :

- Ils connaissent la liste des Préceptes et le pseudo d'Eri.
- Leurs messages dans le chat ne sont lus que par les Préceptes.
- Si un Précepte tue Eri, le QG s'active pendant 6 minutes. `!qg` les téléporte en son cœur pour empêcher la capture. Si la capture échoue, Eri est éliminée et chaque Précepte gagne +1 cœur permanent et +8 % de Force.
{% endhint %}
